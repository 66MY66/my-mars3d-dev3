# DB/T 116-2026 附录 B 符号

来源为用户提供的 `DBT116-2026FDIS.pdf`，PDF 第 16–17 页（印刷页码 10–11）。表 B.1 的 14 类专题符号和表 B.2 的 21 类底图符号直接裁取，不使用 OCHA 或 IconPark 图形替代。

`dbt116-sources.json` 记录源文件 SHA-256、逐符号表号/行号/页面/裁切范围和生成时 SHA-256。提取脚本为 `scripts/extract-dbt116-symbols.py`，依赖 pypdf、pdftocairo。SVG 保留矢量路径和原 PDF 内嵌位图；不是全部矢量，也不声明为 CC0。OCHA 旧素材及其授权继续保留，仅用于旧标注恢复。

颜色为 PDF 经 Cairo 转换后的屏幕参考色。附录 B 中的 CMYK 是参考值；本模块不声称具备印刷 ICC 色彩管理。图库预览使用浅色衬底使黑色符号可辨；主图和导出不额外添加图库衬底。

界线、公路、河流等图形在素材库中是**样式样本**，不是某地的实际空间几何，不能靠拖一个样式样本代替绘制该地真实要素。标准模板按导入的实际几何绘制线面。

该标准发布于 2026-05-27，实施日期为 2026-12-01。本项目根据用户要求提前适配提供的版本，不宣称已获得合规认证。
