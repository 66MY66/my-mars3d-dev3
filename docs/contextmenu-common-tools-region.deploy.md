# 部署/使用说明：右键常用工具（区域标记动态显示）

## 依赖
- 浏览器需支持 `localStorage`
- 前端依赖无需新增额外包

## 开启方式
- 默认已在地图组件中启用，无需额外配置
- 右键触发规则：
  - 无区域：不显示“常用工具”
  - 有区域：仅区域内显示“常用工具”
  - Shift + 右键：强制显示“常用工具”

## 数据持久化
- localStorage Key：`mars3d_region_markers_v1`
- 若发现刷新后区域未恢复：
  - 检查是否有其他逻辑在加载时清空 `map.graphicLayer`
  - 检查浏览器是否禁用 localStorage 或隐私模式限制

## 常见问题
- “区域内右键也不显示常用工具”：
  - 确认标注的区域是多边形，且坐标为经纬度 ring
  - 若区域多边形样式未包含 `#ff7f50`，会被识别为 `generic` 类型；后续若需严格按类型显示，可在图形 attr 中写入 `regionType`
