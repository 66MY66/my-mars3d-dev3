# 2026-07-19 Map Floating Controls

## Modification purpose
- 按用户要求回滚地图页面左下角 7 个悬浮按钮的样式和提示字覆盖，恢复原生/既有主题图标表现。
- 追加优化：仅将左下角“帮助”悬浮按钮图标从“白色圆底 + 深蓝色线条”调整为纯白色线条图标。
- 二次补强：隐藏帮助按钮原生 SVG 绘制层，使用 CSS 伪元素输出纯白线条问号，视觉参考同组放大/缩小按钮。
- 三次优化：参照同层级“缩小 / 放大 / 全屏”按钮的简洁图标表达，将帮助按钮改为居中的单一白色“?”图标，去除叠影加粗处理。

## Modified files
- src/styles/theme.css
- docs/history/2026-07-19-map-floating-controls.md

## Reason for change
- 用户明确要求不要修改左下角 7 个图标样式，需要恢复此前对提示字、按钮圆角、帮助图标和帮助悬浮窗的覆盖。
- 用户后续明确指定只优化“帮助”悬浮图标，要求去掉白色背景圆底，保留白色线条图标。
- 原生帮助 SVG 可能通过非 `circle` 路径绘制圆底，单纯覆盖 fill/stroke 不够稳定，因此改为隐藏原生图形并输出纯线条问号。
- 当前进一步优化图标表达，避免文字叠影造成视觉偏粗，使帮助按钮与同层级缩放、全屏控件保持更一致的轻量线性风格。

## Rollback method
- 当前记录本身是回滚记录。
- 若需要重新应用此前优化，需要重新添加 `mars-map.vue` 中的控件标签同步逻辑，并在 `theme.css` 中恢复“地图左下角悬浮控件”样式块。
- 若本次回滚已提交，优先使用 `git revert <commit>` 撤销该回滚提交。
- 若需回滚本次帮助图标线条化，只移除 `theme.css` 中“地图左下角帮助按钮”样式块即可。
- 若只需回滚本轮图标微调，可恢复该样式块中 `::before` 的字体大小、行高和 `text-shadow` 设置。
