# 2026-07-16 左侧菜单栏（Sidebar）

## 修改目的
- 对照 `docs/UI_DESIGN_SYSTEM.md` 第 7 节「Sidebar System」检查左侧菜单栏是否符合规范。
- 在保留原有背景与布局形式的前提下，仅调整字体字阶，使分组标题与菜单项层级更清晰。

## 修改文件
- `src/shell/Sidebar.vue`
- `docs/history/2026-07-16-sidebar.md`

## 修改原因
- 分组标题原先使用 `14px` 正文字号，与菜单项同级，不符合设计系统中 Caption（`12px`）用于次级标签的规范。
- 用户明确要求：**不新增分组子背景色块**，背景颜色保持原有 `#17233d` 单层形式；除字体外其余样式恢复原版。

## 实际保留的变更
- 分组标题 `.group-title-text`：`12px / 400 / 18px` 行高，`letter-spacing: 0.01em`（原为 `14px`）。
- 菜单文字 `.menu-text`：补充 `line-height: 22px`（字号仍为 `14px`）。

## 已恢复的原版样式
- 侧栏背景 `#17233d`（硬编码，无 token 替换）。
- 内边距与分组间距 `6px`。
- 分组子菜单无 `--layout-sidebar-sub` 背景块。
- 选中态背景 `rgba(92,173,255,0.12)`、左侧高亮条 `var(--syc-submenu-active)`。
- 收起态菜单项高度 `40px`。
- 边缘收起/展开条原有配色与交互。
