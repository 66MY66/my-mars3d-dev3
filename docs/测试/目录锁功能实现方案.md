# 目录锁功能实现方案

## 一、需求背景

### 问题场景

多人协作操作同一数据集时，可能出现：
- 用户A正在处理告警目录，用户B同时修改导致数据覆盖
- 工作流顺序被打乱（告警未确认就发布专题图）

### 解决方案

在 eoAPI 后端实现 `/locks/directories` 端点，提供跨用户的目录锁定功能。

## 三、数据库表设计

### 表结构

```sql
CREATE TABLE IF NOT EXISTS eoapi_directory_locks (
    id              SERIAL PRIMARY KEY,
    directory_id    VARCHAR(255) NOT NULL UNIQUE,  -- 目录ID，唯一约束
    dataset_id      VARCHAR(255) NOT NULL,          -- 所属数据集ID
    directory_type  VARCHAR(50) NOT NULL,           -- 目录类型
    locked          BOOLEAN NOT NULL DEFAULT FALSE, -- 锁定状态
    reason          TEXT,                           -- 锁定原因
    metadata        JSONB,                          -- 扩展元数据
    updated_by      VARCHAR(255) NOT NULL,          -- 锁定操作人
    created_at      BIGINT NOT NULL,                -- 创建时间戳(毫秒)
    updated_at      BIGINT NOT NULL,                -- 更新时间戳(毫秒)
    expires_at      BIGINT                          -- 过期时间戳(可选)
);

-- 性能优化索引
CREATE INDEX IF NOT EXISTS idx_directory_locks_dataset 
    ON eoapi_directory_locks(dataset_id);

CREATE INDEX IF NOT EXISTS idx_directory_locks_locked 
    ON eoapi_directory_locks(locked) WHERE locked = TRUE;
```

### 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `directory_id` | VARCHAR(255) | 目录唯一标识，如 `dir_alert_001` |
| `dataset_id` | VARCHAR(255) | 所属数据集ID，如 `ds_d9ac3fc6d36f` |
| `directory_type` | VARCHAR(50) | 目录类型: `alert`/`thematic`/`task`/`generic` |
| `locked` | BOOLEAN | 是否锁定 |
| `reason` | TEXT | 锁定原因说明 |
| `metadata` | JSONB | 扩展字段，如 `{ "taskId": "xxx" }` |
| `updated_by` | VARCHAR(255) | 最后操作用户ID |
| `created_at` | BIGINT | 创建时间，毫秒时间戳 |
| `updated_at` | BIGINT | 更新时间，毫秒时间戳 |
| `expires_at` | BIGINT | 过期时间（可选，用于自动解锁） |

**参数：**
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| datasetId | string | 是 | 数据集ID |

```json
    "directoryId": "dir_alert_001",
    "datasetId": "ds_d9ac3fc6d36f",
    "directoryType": "alert",
    "locked": true,
    "reason": "正在确认告警",
    "metadata": null,
    "updatedBy": "user_001",
    "createdAt": 1784352781000,
    "updatedAt": 1784352785000
  }
]
```

**错误处理：**
- 表不存在时返回空数组 `[]`

---

### 2. 创建/更新目录锁

**请求：**
```http
POST /locks/directories/{directoryId}?user_id={userId}
Content-Type: application/json

{
  "datasetId": "ds_d9ac3fc6d36f",
  "directoryType": "alert",
  "locked": true,
  "reason": "正在确认告警",
  "metadata": { "taskId": "task_001" }
}
```

**参数：**
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| directoryId | string | 是 | 目录ID（路径参数） |
| user_id | string | 是 | 操作用户ID（查询参数） |

**请求体：**
| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| datasetId | string | 是 | - | 数据集ID |
| directoryType | string | 否 | `task` | 目录类型 |
| locked | boolean | 是 | - | 锁定状态 |
| reason | string | 否 | null | 锁定原因 |
| metadata | object | 否 | null | 扩展元数据 |

**响应：**
```json
{
  "directoryId": "dir_alert_001",
  "datasetId": "ds_d9ac3fc6d36f",
  "directoryType": "alert",
  "locked": true,
  "reason": "正在确认告警",
  "metadata": { "taskId": "task_001" },
  "updatedBy": "user_001",
  "createdAt": 1784352781000,
  "updatedAt": 1784352785000
}
```

**行为说明：**
- 使用 PostgreSQL UPSERT (`ON CONFLICT DO UPDATE`)
- 首次调用创建记录，后续调用更新记录
- 返回完整锁记录

---

### API 端点实现

```python
@app.get("/locks/directories", response_model=list[DirectoryLockRecord])
async def get_directory_locks(
    datasetId: str = Query(..., description="数据集ID")
):
    """查询指定数据集下所有目录锁"""
    dsn = _db_dsn()
    rows = []
    
    try:
        with psycopg.connect(dsn) as conn:
            with conn.cursor() as cur:
                cur.execute(
                    """
                    SELECT directory_id, dataset_id, directory_type, locked, 
                           reason, metadata, updated_by, created_at, updated_at
                    FROM eoapi_directory_locks
                    WHERE dataset_id = %s
                    """,
                    (datasetId,)
                )
                for r in cur.fetchall():
                    rows.append(DirectoryLockRecord(
                        directoryId=r[0],
                        datasetId=r[1],
                        directoryType=r[2],
                        locked=r[3],
                        reason=r[4],
                        metadata=r[5],
                        updatedBy=r[6],
                        createdAt=r[7],
                        updatedAt=r[8]
                    ))
    except Exception:
        # 表不存在时返回空列表
        pass
    
    return rows


@app.post("/locks/directories/{directory_id}", response_model=DirectoryLockRecord)
async def upsert_directory_lock(
    directory_id: str,
    user_id: str = Query(..., description="用户ID"),
    body: UpsertDirectoryLockRequest = ...
):
    """创建或更新目录锁状态"""
    dsn = _db_dsn()
    now = _now_ms()
    
    try:
        with psycopg.connect(dsn) as conn:
            with conn.cursor() as cur:
                cur.execute(
                    """
                    INSERT INTO eoapi_directory_locks 
                        (directory_id, dataset_id, directory_type, locked, 
                         reason, metadata, updated_by, created_at, updated_at)
                    VALUES (%s, %s, %s, %s, %s, %s, %s, %s, %s)
                    ON CONFLICT (directory_id) DO UPDATE SET
                        dataset_id = EXCLUDED.dataset_id,
                        directory_type = EXCLUDED.directory_type,
                        locked = EXCLUDED.locked,
                        reason = EXCLUDED.reason,
                        metadata = EXCLUDED.metadata,
                        updated_by = EXCLUDED.updated_by,
                        updated_at = EXCLUDED.updated_at
                    RETURNING created_at
                    """,
                    (
                        directory_id,
                        body.datasetId,
                        body.directoryType or "task",
                        body.locked,
                        body.reason,
                        psycopg.types.json.Jsonb(body.metadata or {}),
                        user_id,
                        now,
                        now
                    )
                )
                result = cur.fetchone()
                conn.commit()
                
                created_at = result[0] if result else now
                
                return DirectoryLockRecord(
                    directoryId=directory_id,
                    datasetId=body.datasetId,
                    directoryType=body.directoryType or "task",
                    locked=body.locked,
                    reason=body.reason,
                    metadata=body.metadata,
                    updatedBy=user_id,
                    createdAt=created_at,
                    updatedAt=now
                )
    except Exception as e:
        raise HTTPException(status_code=500, detail=str(e))


@app.delete("/locks/directories/{directory_id}")
async def delete_directory_lock(
    directory_id: str,
    user_id: str = Query(..., description="用户ID")
):
    """删除目录锁"""
    dsn = _db_dsn()
    
    try:
        with psycopg.connect(dsn) as conn:
            with conn.cursor() as cur:
                cur.execute(
                    "DELETE FROM eoapi_directory_locks WHERE directory_id = %s",
                    (directory_id,)
                )
                conn.commit()
                return {"success": True, "deleted": cur.rowcount > 0}
    except Exception as e:
        raise HTTPException(status_code=500, detail=str(e))
```

## 十一、注意事项

1. **权限控制**: 当前设计通过 `user_id` 参数传递用户身份，生产环境应使用认证中间件
2. **并发安全**: PostgreSQL 的 UPSERT 保证了原子性
3. **数据一致性**: 删除数据集时应级联删除相关锁记录
4. **监控告警**: 可添加日志记录锁操作，用于审计
