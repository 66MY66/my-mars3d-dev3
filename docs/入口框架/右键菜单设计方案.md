# 右键菜单精简设计文档

> 版本：V1.5
> 编制日期：2026-04-08
> 状态：待确认

---

## 一、设计原则

| 原则 | 说明 |
|------|------|
| **高频直达** | 最常用操作（复制坐标、标记）一级菜单直接可用 |
| **绘制即测量** | 绘制线/面时自动显示测量结果，无需单独测量功能 |
| **上下文感知** | 根据点击对象类型展示不同菜单项 |
| **流程衔接** | 分析工具放在标记对象右键，先有对象再分析 |
| **操作可预期** | 清理等危险操作前确认并显示影响范围 |

## 二、统一右键菜单（空白处/图层对象共用）

**触发条件**：
- 右键点击地图空白区域（未命中任何对象）
- 右键点击 WMS/WMTS/Tiles3D 等图层要素

```
┌─────────────────────────────┐
│ 📍 复制坐标                 │  ← 点击即复制到剪贴板
├─────────────────────────────┤
│ 📌 在此标记                 │  ← 在右键位置直接添加点标记
├─────────────────────────────┤
│ ✏️ 绘制  ▶                  │
│   ├─ 绘制线                 │  ← 自动显示距离
│   ├─ 绘制面                 │  ← 自动显示面积
│   ├─ 绘制矩形               │
│   └─ 添加文字注记           │
├─────────────────────────────┤
│ 🎯 定位到图层               │  ← 仅图层对象显示
├─────────────────────────────┤
│ 🔍 调整透明度  ▶            │  ← 仅图层对象显示
│   ├─ 25%                    │
│   ├─ 50%                    │
│   ├─ 75%                    │
│   └─ 100%                   │
├─────────────────────────────┤
│ 📋 图层信息                 │  ← 仅图层对象显示
├─────────────────────────────┤
│ 🔥 异常检测                 │  ← 智能判断：有面用面，无面提示绘制
├─────────────────────────────┤
│ 🏷️ 标记为异常点             │  ← 在右键位置添加异常点标记
├─────────────────────────────┤
│ 🗑️ 清理临时要素             │  ← 弹窗确认清理内容
└─────────────────────────────┘
```

### 功能说明

| 菜单项 | 功能描述 | 显示条件 | 交互细节 |
|--------|----------|----------|----------|
| **复制坐标** | 复制点击位置坐标到剪贴板 | 始终显示 | Toast 提示：`已复制: 116.407, 39.904` |
| **在此标记** | 在右键位置添加点标记 | 始终显示 | 直接添加，无需二次操作 |
| **绘制线** | 绘制折线 | 始终显示 | 绘制过程中实时显示距离，完成后显示总长度 |
| **绘制面** | 绘制多边形 | 始终显示 | 绘制过程中实时显示面积，完成后显示总面积 |
| **绘制矩形** | 绘制矩形框选 | 始终显示 | 用于快速框选分析区域 |
| **添加文字注记** | 添加文本标注 | 始终显示 | 弹出输入框，输入后点击放置 |
| **定位到图层** | 飞行到图层范围 | 仅图层对象 | - |
| **调整透明度** | 设置图层透明度 | 仅图层对象 | 4 档可选 |
| **图层信息** | 弹窗显示图层详情 | 仅图层对象 | 显示名称、类型、来源、范围等 |
| **异常检测** | 检测区域异常 | 始终显示 | 智能判断：存在面则直接分析，不存在则提示绘制 |
| **标记为异常点** | 添加异常点标记 | 始终显示 | 添加红色标记点，属性标记为异常 |
| **清理临时要素** | 清除所有临时内容 | 始终显示 | 弹窗确认，显示将清理的要素数量 |

### 异常检测智能流程

```
用户选择"异常检测"
    ↓
系统检测是否存在已绘制的面？
    ├─ 存在 1 个面 → 直接使用该面进行分析
    ├─ 存在多个面 → 弹窗让用户选择
    └─ 不存在面 → 提示"请先绘制分析区域"
                   ↓
                   自动启动"绘制面"工具
                   ↓
                   绘制完成后自动继续分析
```

## 八、综合统计面板

### 8.1 面板定位与入口

| 属性 | 说明 |
|------|------|
| 面板名称 | 综合统计面板 |
| 触发入口 | 右键菜单「查看统计」（点标记/面标记） |
| 默认尺寸 | 420px × 600px |
| 位置记忆 | localStorage 保存位置与尺寸 |

### 8.2 与异常识别的关系

| 面板 | 定位 | 交互关系 |
|------|------|----------|
| 综合统计面板 | 统计分析、数据概览 | 提供「异常识别」按钮，跳转并带入当前区域 |
| 异常识别面板 | 空间异常检测、结果可视化 | 提供「综合统计」按钮，返回并带入当前区域 |

### 8.3 数据源定义

| 数据源 | 类型 | 说明 | 优先级 |
|--------|------|------|--------|
| 告警数据 | 实时 | 当前区域内的告警记录 | P0 |
| 历史灾害 | 归档 | 历史灾害事件记录 | P0 |
| 监测站点 | 静态 | 区域内监测点分布 | P1 |
| 人口底数 | 静态 | 行政区人口统计数据 | P1 |
| 经济底数 | 静态 | 行政区经济统计数据 | P2 |

### 8.4 明细表字段定义

| 字段 | 类型 | 说明 | 必选 |
|------|------|------|:----:|
| id | string | 唯一标识 | ✅ |
| name | string | 名称/编号 | ✅ |
| type | string | 类型（告警类型/灾害类型） | ✅ |
| level | string | 等级（严重程度） | ✅ |
| status | string | 状态（待处理/已处理/已忽略） | ✅ |
| location | string | 位置（行政区名称或坐标概要） | ✅ |
| lng | number | 经度 | ✅ |
| lat | number | 纬度 | ✅ |
| time | datetime | 发生/上报时间 | ✅ |
| source | string | 数据来源 | ❌ |
| description | string | 详细描述 | ❌ |

### 8.5 Tab 结构与优先级

| Tab | 目标用户场景 | 优先级 | 首期实现 |

| 趋势预测 | “未来趋势如何？需要预警吗？” | P2 | ❌ |

### 8.14 接口规范

#### 统计查询接口

**请求**
```http
POST /api/v1/analytics/query
Content-Type: application/json

{
  “region”: {
    “type”: “ring”,           // ring | regionId | buffer
    “coordinates”: [[lng, lat], ...],  // 环坐标
    “center”: [lng, lat],     // buffer 类型时使用
    “radius”: 1000            // buffer 类型时使用，单位米
  },
  “timeRange”: {
    “start”: “2026-03-01”,
    “end”: “2026-04-08”,
    “granularity”: “day”      // day | week | month
  },
  “filters”: {
    “types”: [“热异常”, “形变异常”],
    “levels”: [“严重”, “中等”],
    “status”: [“待处理”]
  },
  “groupBy”: [“type”, “level”],  // 分组维度
  “metrics”: [“count”, “sum”],   // 聚合指标
  “page”: {
    “pageNum”: 1,
    “pageSize”: 10
  }
}
```

**响应**
```json
{
  “code”: 0,

    },

      “type”: [{ “name”: “热异常”, “value”: 12, “percent”: 52.2 }],
      “level”: [{ “name”: “严重”, “value”: 3, “percent”: 13.0 }]

      “total”: 98,
      “rows”: [
        { “id”: “HA-2026-001”, “name”: “热异常-001”, “type”: “热异常”, “level”: “严重” }
```
