# 人口与 GDP 格网真实统计设计

## 目标

综合统计面板的人口、经济卡片使用 2020 年人口/GDP COG 数值栅格生成真实二维图表，不再使用面积参数估算和随机拆分。

## 数据与规则

- 人口：`SP-china-pop2020`，数值单位人/平方公里。
- GDP：`SP-china-gdp2020`，数值单位万元/平方公里。
- 两份栅格均为 EPSG:4326、0.005°、nodata=-9999。
- 绘制面与每个候选像元求交；覆盖率大于或等于 40% 时纳入完整像元，低于 40% 时排除。
- 总量为密度乘像元实际面积后求和，不直接使用密度值之和。
- 人口和经济图表按源数据图例的密度区间分组，不再按行政区分组。
- 上图展示使用同一 STAC Item 的 visual 影像，并限制在当前绘制范围。

## 约束

- 同一绘制面重复统计结果一致，不受相机缩放影响。
- 只读取绘制范围覆盖的 COG 窗口；超大窗口应拒绝并提示缩小范围，避免浏览器失去响应。
- 不修改图层树中原始人口/GDP图层的显示状态。
