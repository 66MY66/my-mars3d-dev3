## 一、入口与通用交互

- 入口：在地图上对“标记面区域”右键，进入“常用工具”，选择：
  - 缓冲区分析 / 叠加分析 / 邻域分析
- 通用能力：
  - 点击“开始分析”后自动上图
  - 点击“清除结果”清理上次分析结果
  - 支持导出 GeoJSON/CSV（结果/点列表）

说明：
- 当前支持的分析目标为 `polygon ring (WGS84)`，由右键命中的标记面提供。

## 二、缓冲区分析

### 作用
以地震相关实体（震中、断裂带、救援站点等）为基础，构建一定距离的影响范围，解决“邻近度/影响半径”问题。

### 系统实现
- 支持两种模式：
  - 多环缓冲（默认）：核心区/过渡区/边缘区
  - 单环缓冲：单一半径
- 默认分级半径（km）：
  - 核心区：0–50km（红）
  - 过渡区：50–100km（橙）
  - 边缘区：100–150km（黄）
  
几何说明：
- 多环缓冲采用“环带面（donut）”表达方式：核心区为实心面，过渡区/边缘区为带洞多边形，三层互不重叠。

单位说明：
- 缓冲区半径支持 km/m 切换；实际接口建议统一使用米（m）传输，前端仅负责展示单位换算。

### 呈现方式
- 地图：自动生成 1–3 个缓冲多边形图层（半透明填充 + 描边）
- 面板：显示缓冲类型与关键半径，并在图例中解释颜色含义

## 三、叠加分析

### 作用
对多个空间数据层进行集合运算（交/并/差），用于识别重叠风险区域或空间关联。

### 系统实现
- 运算方式：
  - 交集 / 并集 / 差集(A-B)
- 目标图层（当前提供 mock 选项，后续由后端返回业务图层清单）：
  - 模拟-行政区
  - 模拟-隐患面

### 呈现方式
- 地图：同时上图三层（便于解释）：
  - A：高烈度区（红）
  - B：人口密集区（蓝）
  - Result：高风险重叠区（紫）
- 面板：显示运算方式、结果是否为空、结果面积/周长（若有）

## 四、邻域分析（隐患点）

### 作用
以中心区域为基准，统计周围邻域内的局部特征（如隐患点分布、风险强度等）。

### 系统实现
- 数据集：隐患点（优先）
- 半径：以米为单位
- 呈现方式：
  - 热力图+点 / 仅点 / 仅热力图
- TopN 列表：
  - 按隐患等级排序（level 3 优先）
  - 点击列表条目可定位到地图对应点位（flyTo + 高亮）

### 呈现方式
- 地图：
  - 邻域范围面（橙）
  - 隐患点（黄/橙/红表示等级）
  - 邻域热力图（深绿→黄→红表示风险强度）
- 面板：
  - 统计摘要（点数量、半径、面积/周长）
  - 隐患点列表（TopN，可调）
  - 支持导出 CSV（点列表）与 GeoJSON（完整结果）

## 五、后端对接建议（接口输出）

建议后端统一输出：
- `geojson: FeatureCollection`
  - 至少包含一个 Polygon（邻域范围/叠加结果/缓冲区）
  - 可包含多个 Point（邻域隐患点）
- `summary: Record<string, any>`
  - 缓冲区：core/transition/edge 半径与面积/周长（可选）
  - 叠加：operation、area、perimeter、empty
  - 邻域：count、radius、热力参数、分类统计（可扩展）
