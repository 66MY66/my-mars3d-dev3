# 测试报告：右键常用工具（区域标记动态显示）

## 覆盖范围
- 无标记：命中检测返回空
- 单区域标记：区域内命中，区域外不命中
- 多区域标记：能命中正确区域
- 边界与坐标输入：坐标为非数值/环点不足等情况返回 false
- 性能：1000 个区域场景下，单次命中检测耗时 < 100ms（合成数据）

## 自动化测试
- 用例文件：[region-hit.test.ts](file:///d:/work/mars3d/src/utils/region-hit.test.ts)
- 运行命令：
  - `npm run test:unit`

## 性能基准说明
- 基准测试在 Vitest 环境（Node + jsdom）内完成，数据为规则网格正方形环。
- 实际线上性能还与区域形状复杂度（点数量）、浏览器 JS 引擎、机器性能有关；算法层面采用 bbox 预过滤，复杂度约为 `O(N * K_hit)`（N 为区域数，K_hit 为命中候选的平均多边形边数）。

## 兼容性验证（人工测试建议）
- Chrome / Edge / Firefox / Safari：
  - 创建区域 → 区域内右键出现“常用工具”
  - 区域外右键不出现“常用工具”
  - Shift + 右键强制出现“常用工具”
