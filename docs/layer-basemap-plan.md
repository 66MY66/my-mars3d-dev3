# 图层管理与底图实施计划（落地版）

## 目标
- 图层管理：稳定显隐与透明度控制、快速检索与分组、右键效率功能、属性详情规范化、状态持久化。
- 底图：稳定切换、状态记忆、地形开关统一（标题栏右侧）、分组与搜索、与专题联动、可对接后端配置。

## 阶段与交付
- A1 稳定性与状态记忆（优先）
  - 图层勾选仅控制显隐，双击节点飞行定位
  - 本地存储 show/opacity/zIndex 并在启动时恢复
  - 底图/地形状态持久化与反馈提示
- A1.5 业务场景梳理与图层组合定义（优先，影响后续 UI 结构与默认展示）
  - 梳理业务场景（宏观异常/前兆异常/形变观测/风险监测/灾损评估等）并定义“图层组合”
  - 每个场景输出：推荐底图、默认开启图层、互斥图层、分析结果归档组
  - 形成可配置化产物：`src/config/layer-presets.json`（后续可迁移到后端）
- A2 体验增强
  - 图层分组（底图/业务/分析结果/标注），节点信息密度提升（类型 tag、透明度 slider）
  - 底图分组与搜索，预览统一
- A3 联动能力
  - 底图与专题图层联动（切底图自动打开关联图层）
  - 分析结果图层统一前缀与快速筛选
- A4 配置与后端对接（可选）
  - 合并本地与服务端底图清单/权限控制
  - 图层 metadata 结构化并对接服务

## 接口与数据
- 图层状态存储键：`mars3d_layers_state_v1`，字段：`{ id, show, opacity, zIndex }`
- 底图状态存储键：`mars3d_basemap_state_v1`，字段：`{ basemapId, hasTerrain }`
- 底图联动配置：`basemap.presets.json`（可后续迁移到后端）
- 图层组合配置：`src/config/layer-presets.json`（业务场景 → 图层组合）
- 属性详情字段规范：`{ name,type,id,url,provider,timeRange,metadata }`

## 验收
- 图层：勾选/取消不飞行，双击节点定位；刷新后 show/opacity 保持；右键排序正确
- 底图：切换与地形开关 1s 内响应；刷新后状态保持；分组与搜索有效

## 风险与缓解
- 大数据量树卡顿：搜索防抖、按需渲染、避免在节点挂载大对象
- WebGL 性能：启用 requestRenderMode、关闭 preserveDrawingBuffer、提供性能模式开关
