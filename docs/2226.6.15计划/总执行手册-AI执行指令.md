# 总执行手册-AI执行指令

## 任务目标
- 按《总执行手册》统一推进当日开发、联调、测试、验收全过程。
- 在保留现有分文档结构不变的前提下，以本指令作为总入口执行。

## 操作步骤
1. 先完整阅读《总执行手册》，确认适用范围、编号纠偏、执行原则。
2. 按“第一部分：总执行清单”锁定工单范围和优先级。
3. 按“第二部分：时间轴排程”推进阶段任务，不得随意打乱顺序。
4. 对 `4-29 ~ 4-44` 按“第三部分：统计面板专项拆分”逐项执行验收收口。
5. 每完成一个工单后，立即按“第四部分：执行记录模板”补录执行记录。
6. 统一按“第五部分：统一测试与验收要求”执行 lint、自测、联调和验收。
7. 完成后按“第六部分：交付清单”输出最终成果。
8. 若需查看明细，回到“第七部分：关联分文档”中的对应文档继续执行。

## 校验标准
- 不得跳过编号纠偏要求，不得混淆 `2-17`、`2-21`、`2-22`。
- 不得对已形成闭环的模块做无必要重写。
- 每个工单都必须保留修改文件、自测命令、人工验证结果和风险说明。
- 测试阶段必须保证 `pnpm -C /program/Mars3D/mars3d lint` 通过。
- 验收结论必须明确输出：通过 / 有条件通过 / 不通过。

## 交付要求
- 输出逐工单执行记录。
- 输出阶段性完成情况和阻塞说明。
- 输出统一测试结果和验收报告。
- 输出剩余风险与最终闭环结论。
