# P1-P7 全量节点拆解表

## 执行顺序
- AI 按 `P1 -> P2 -> P3 -> P4 -> P5 -> P6 -> P7` 推进；每个能力包内部严格按节点顺序执行。
- 每个节点统一输出：`节点编号、执行结果、输出物、校验结论、遗留问题、下一步`。
- 任一节点结论为 `不通过` 或 `阻塞` 时，停止进入下一个节点，先完成返工或阻塞处理。
